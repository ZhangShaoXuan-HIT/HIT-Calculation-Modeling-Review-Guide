## 一、例题精解与知识点巩固（`examples.html`）

对课程课件（9 个 PPT，共 1036 页）的系统整理。整理遵循三条原则：

1. **原题不失真** —— 课件中每道例题都保留原题面的全部数据与条件；
2. **推导不跳步** —— 解答按课堂推导顺序重排，补足被幻灯片省略的中间运算；
3. **考点先铺垫** —— 每道例题之前先给出该考点所需的知识点与公式，再进入解题。

章节覆盖：

| 章节 | 主要内容 |
| :--- | :--- |
| 第 1 章 | 概率论回顾 —— 概率空间、Bayes 公式、常见分布、矩、条件期望、极限定理 |
| 第 2 章 | 参数估计 —— 评价准则、最小二乘、最大似然、贝叶斯估计、EM 算法 |
| 第 3 章 | 随机过程的概念和基本类型 —— 有限维分布族、均值与相关函数、严平稳与宽平稳、泊松过程 |
| 第 5 章 | 马尔科夫链 —— 转移矩阵、C–K 方程、状态分类、平稳分布与遍历性 |
| 第 6 章 | 生灭过程与泊松过程 —— 生灭过程平稳分布、泊松的两种定义、到达时间与复合泊松 |
| 第 8 章 | 卡尔曼滤波 —— 状态空间模型与五个基本方程、矩阵卡尔曼、扩展卡尔曼与信号检测 |
| 第 9 章 | 图模型基础 —— 判别式与生成式、朴素贝叶斯与贝叶斯网络、MRF / Gibbs / CRF |
| 第 10 章 | 随机模拟 —— 随机数生成与抽样、蒙特卡罗积分与方差缩减、MCMC 与 RANSAC |
| 第 11 章 | 最优化求解 —— 线性规划与图解法、单纯形与对偶、凸性与最优性条件、深度学习优化器 |

> 注：课件共 11 章，其中第 4 章（平稳随机过程的谱分析）与第 7 章（高斯过程与维纳过程）未单独成册，内容分散在第 3、8 章的讲义中。本资料按实际到手的 9 个课件分章整理，章节编号沿用课件原编号。

全资料共收录例题卡片 **183 张**、自编巩固练习 **93 道**（其中应用题 62 道、论述题 31 道），均标注课件页码以便回查原片。

## 二、冲刺复习（`crash-review.html`）

考前一天用的版本。不按章节走，而是按**公式手册的考点**重新编排，把散在各章的同一类题目聚到一起。

- **第一部分 填空（12 分）** —— 公式速记与秒算：C–K 方程、n 步转移、维纳–辛钦、极大似然、协方差、非齐次泊松、特征函数、线性规划标准型
- **第二部分 简答（4 题）** —— 背模板、写术语：卡尔曼滤波、DCT 与图像缩放、RANSAC、GMM 与 EM 聚类
- **第三部分 应用（5 题）** —— 把计算做到底：区间计数、平稳分布即市场占有率、正交增量过程、路径概率连乘、功率谱计算
- **附录 A** 考前 30 分钟：一页纸清单
- **附录 B** 易错二十条
- **附录 C** 考场节奏

每个考点标注了对应的公式编号与题型出处（如 `公式 02｜填空 1，应用 2、4`），方便反向定位到 `examples.html` 里的详细推导。带【补充】标记的是课件未直接给出、但考试可能用到的延伸内容。

## 使用方式

**在线看** —— 点上面的链接，或直接访问 <https://zhangshaoxuan-hit.github.io/HIT-Calculation-Modeling-Review-Guide/>

**本地看** —— 下载任意一个 `.html` 文件，双击用浏览器打开。单个文件即完整文档，不依赖同目录下的其他文件。

**打印** —— 两份文档都内置了打印样式，`Ctrl + P` 直接输出 PDF，侧边栏会自动隐藏，公式不会断行。

**手机看** —— 响应式布局，窄屏下侧边栏收为顶部导航。
